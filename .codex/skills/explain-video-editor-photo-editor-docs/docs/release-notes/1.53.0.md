## List of changes

### New Video Editor UI Set as Default

The redesigned video editing interface (Editor V2) is now enabled by default on both Android and iOS. The legacy editor remains available for backward compatibility but is deprecated and scheduled for removal in late 2026. We recommend migrating to the new UI to ensure future compatibility.

### Dark Theme Support for Photo Editor

The Photo Editor SDK now supports dynamic Light/Dark theme switching.

> ❗ Dark theme is used by default.
> - Android: pass `applyDarkTheme = false` to the `startFrom*` methods of `PhotoCreationActivity` to use Light theme.
> - iOS: set `BNBDesignSystem.theme = .light` (via `BanubaDesignSystem`) before presenting the editor to use Light theme.

### Removal of Video and Photo Sharing Screens

The built-in post-export sharing screens have been removed from both the Video Editor and Photo Editor SDKs. Developers now handle the export result via delegate/callback and implement their own sharing UI.

### New feature - Video Speed effect in NEW UI (Android)

Introduces a new Speed effect within the redesigned video editing interface. This feature enables users to apply time-scaling to video segments, ensuring that the modified playback speed is fully rendered and preserved in the final exported file.

### Picture in Picture moved to Layouts (iOS)

PiP is now managed from the Layouts flow on the camera screen (Spotlight mode). The standalone PiP button and related configuration UI were removed.

> ❗ The feature requires the Picture in Picture feature enabled. Without Picture in Picture, this feature will not appear or function. Contact Banuba representatives to enable it.

### Open Photo Editor SDK with light or dark theme - Android

A new argument `applyDarkTheme` was added to the `startFrom*` methods of `PhotoCreationActivity` to manage theme. Example, to start Photo Editor from the Gallery screen in Light theme:

```kotlin
val intent = PhotoCreationActivity.startFromGallery(
    context = ...,
    config = ...,
    extras = ...,
    applyDarkTheme = false // Light theme
)
```

### Open Photo Editor SDK with light or dark theme - iOS

Set the static `BNBDesignSystem.theme` property before presenting the editor to control the theme. Example, to launch Photo Editor from the Gallery screen in Light theme:

```swift
import BanubaDesignSystem

BNBDesignSystem.theme = .light

let photoEditorSDK = BanubaPhotoEditor(
  token: token,
  configuration: PhotoEditorConfig()
)
photoEditorSDK?.delegate = self
let launchConfig = PhotoEditorLaunchConfig(
  hostController: self,
  entryPoint: .gallery
)
photoEditorSDK?.presentPhotoEditor(
  withLaunchConfiguration: launchConfig,
  completion: nil
)
```

### Continue using the legacy editor (iOS)

To continue using the legacy editor temporarily, pass `USE_EDITOR_V2: false` in the Video Editor arguments:

```swift
videoEditorSDK?.updateVideoEditorArgs([ VideoEditorArg.useEditorV2: false ])
```
