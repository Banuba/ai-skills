## List of changes

### Simplified Video Editor SDK Integration (Android and iOS)

A streamlined Banuba Video Editor SDK integration based on a single `VideoEditorSDK` entry point and a Builder. The legacy integration is still available with no urgent migration needed, though future development focus will center on this simplified process.

This release is a major architectural refactoring of the Video Editor SDK to drastically simplify adoption, reduce integration friction, and eliminate external dependency management burdens for host applications.

Key improvements:

- **Android:** zero Koin DI interaction. Internal dependencies are fully encapsulated within the SDK, so the previous classes that used Koin can be removed.
- **Android:** bundled color filters. LUTs and texture files are packaged inside the SDK with zero manual asset setup required.
- **iOS:** builder-based setup. Configure the editor UI, camera, features, and Audio Browser provider in one place.
- **iOS:** single entry point. Launch the editor, configure exports, and handle callbacks through `VideoEditorSDK`.
- **Backward compatibility:** previous integration methods remain functional; migration is optional right now, but future SDK focus and improvements will target the new simplified approach.

### New feature - Collapsible Timeline (Android and iOS)

The Collapsible Timeline gives a larger video preview by letting users collapse the effect and video timelines. Available in the new Editor UI, this editing mode simplifies video editing, much like Instagram or TikTok. Timelines can be collapsed or expanded manually at any time to switch between detailed trimming and an immersive preview.

### Light Theme Support (Beta) (iOS)

The Video Editor SDK now supports a light theme as a beta feature available only in the new Video Editor UI (V2). The editor uses the dark theme by default, and the app can opt in to the light theme through `BNBDesignSystem`.

### Improved accessibility (iOS)

VoiceOver support and accessibility labels have been expanded across the Camera, Gallery, Video Editor V2, and Photo Editor. Key controls in the sticker and text editing flows are now easier to identify and navigate.

### New Video Editor SDK Integration (optional)

You can remove previous classes that used Koin.

```kotlin
val editorSdk = VideoEditorSDK.Builder(applicationContext).apply {
    // Optional AudioBrowser module for music providers: BanubaMusic, Soundstripe, Local
    addModule(AudioBrowserKoinModule().module)
    // Required if AudioBrowser is added.
    setMusicTrackProvider(AudioBrowserMusicProvider())

    // Optional Banuba Gallery module for selecting videos and photos from device
    addModule(GalleryKoinModule().module)

    // Optional module to enable Face AR product
    addModule(BanubaEffectPlayerKoinModule().module)
}.initialize(LICENSE_TOKEN)
```

If the license token is invalid or expired, `editorSdk` will return `null`.

Please contact Banuba support if some features are missing in the `VideoEditorSDK` class.

### New Video Editor SDK Integration

```swift
let editorSDK = VideoEditorSDK.Builder()
  // Optional: enable the V2 editor interface (disabled by default).
  .setEditorV2Enabled(true)
  // Optional: set Audio Browser provider
  .setAudioBrowserProvider(.banuba)
  .initialize(token: licenseToken)
```

`editorSDK` is `nil` if the token is not correct.

Please contact Banuba support if some features are missing in the `VideoEditorSDK` class.

### Light Theme Support (Beta)

Set the theme before presenting the editor so its screens and supported components use the light appearance:

```swift
import BanubaDesignSystem

BNBDesignSystem.theme = .light

let editorSDK = VideoEditorSDK.Builder()
  .setEditorV2Enabled(true)
  .initialize(token: token)

editorSDK?.launch(with: launchConfig)
```
